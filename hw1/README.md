# ДЗ №1: обёртка над ручной инструкцией

`deploy-hdfs.sh` последовательно выполняет шаги из `hadoop-guide.txt`.
Рядом: `prepare-node.sh` (шесть команд подготовки) и четыре обычных файла в `hw01-conf/`.
Нужно передавать **всю папку**, не один `.sh`. Исходный файл сокомандницы не менялся.

## Первый запуск

Только чистые ВМ: не должно быть прежнего `/home/hadoop` и данных Hadoop в `/tmp/hadoop-hadoop`.
Схема: edge; NN + SNN + DN на `team-33-nn`; ещё две DN на `team-33-00` и `team-33-01`.
Ubuntu 24.04 amd64, Java 11, Hadoop 3.4.0. Адреса — из письма преподавателя.

Перед запуском согласовать одного оператора. На edge войти под `team`,
распаковать файлы в одну папку, перейти в неё и выполнить:

```bash
bash deploy-hdfs.sh --init-hdfs
```

Нужны sudo без пароля, интернет и `~/.ssh/team_internal` на edge.
Host keys внутренних ВМ у `team` должны быть уже проверены.
Запускать из обычного интерактивного терминала; на edge подключаться через `ssh -t`.
После подготовки каждого узла обёртка запускает `sudo passwd hadoop`: ввести надёжный пароль
и повторить его. Ввод скрыт; пароль не записывается в скрипты и не передаётся аргументом команды.
Можно задать один пароль на всех четырёх узлах, как на семинаре, и сохранить его в менеджере паролей.
Для SSH между узлами по-прежнему используются ключи; настройки парольного входа SSH не меняются.
Приватные ключи не переносить и не публиковать: обёртка передаёт только публичные части.
Архив проверяется по [SHA-512 Apache](https://archive.apache.org/dist/hadoop/common/hadoop-3.4.0/hadoop-3.4.0.tar.gz.sha512)
штатной [командой GNU sha512sum](https://www.gnu.org/s/coreutils/manual/html_node/cksum-common-options.html).

Это **одноразовая установка**, не инструмент восстановления. После ошибки не перезапускать
вслепую: часть шагов могла выполниться. Полного автоматического отката нет.
При наличии прежнего `/home/hadoop` или каталога NameNode обёртка остановится без повторного format.

## Проверка результата

После запуска открыть UI через туннель из пункта 9 `hadoop-guide.txt`.
Ожидаются три live DN без деградировавших узлов. Дополнительно на NN под `team`:

```bash
sudo -H -u hadoop /home/hadoop/hadoop-3.4.0/bin/hdfs dfsadmin -report
sudo -H -u hadoop /usr/lib/jvm/java-11-openjdk-amd64/bin/jps -l
```

В `jps` должны быть NameNode, SecondaryNameNode и DataNode.
Сохранить скриншот UI для сдачи. Перезапуск — без format, по ручной инструкции.
